# Voice and copy

Use calm, direct language and sentence case. Name an action with a verb: Save article, Open book, Connect Goodreads. State errors plainly and offer a useful next action. Use “Could not connect. Check the address and try again.” rather than unexplained error codes.

Use descriptive headings and native action labels. Product profiles and actual product documentation govern feature claims. Describe connected products and supported platforms accurately. The suite signature describes membership and carries no account or sync promise.
